Table Keeper Privacy Policy

Last updated 8 November 2026 (live tables now use relays)

Table Keeper is a free tool for running Dungeons & Dragons games. It is built to keep your data on your own device. There are no accounts, no adverts and no analytics.

What the app stores

Your campaigns, characters, monsters and notes are saved only in your device's browser storage. We never receive them. If you clear the app's data or uninstall it, they are deleted.

Live tables

When a DM starts a live table, other players can join with a 6-character code. Party details (names, stats, HP, conditions, spell slots, items and the initiative order) are then shared between the devices at the table.

  • These updates travel through two free public messaging relays, EMQX (broker.emqx.io) and HiveMQ (broker.hivemq.com), so players can join from any Wi-Fi or mobile network. The relays pass the messages on and keep the latest party snapshot for that table code until the DM ends the table. Anyone who knows the code could read it, so the code works like a password.
  • Monster HP, AC and attacks are never shown to players. So the DM can open a campaign on another device, an encrypted copy of the DM's campaign is also kept on the relays. It is locked with the DM password, which never leaves the DM's device.
  • Anyone with the table code can view and edit the party while the table is live. Only share the code with people at your game.

Other services

The app loads its fonts from Google Fonts and the live-table library from unpkg.com, and live tables use the relays named above. Like any website, these services receive your IP address when you download those files. We don't share any other information with them.

Children

The app doesn't collect personal information from anyone, including children.
